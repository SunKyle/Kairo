## 三、文档编号规则

1. 编号由一段字母 + 一位数字组成：P（产品）、A（对话/角色）、C（创建）、I（接口/发图）、G（配图）、B（架构）、D（设计/维护）。
2. 编号是稳定引用：以后只要文档内容不变，编号就不往返改。
3. 新文档在新增时，给它分配一个编号，不复用旧编号。

## 五、常见问题

- 文档目录为什么不是按文件名排的？因为按编号组织更容易按主题找。
- 对话沉浸感设计.md 和 沉浸式对话页面设计.md 为什么不在了？已合并为 沉浸式对话.md。
- 为什么 Kairo项目梳理（现状）.md 改名了？改成 现状梳理（当前状态）.md，含义更明确：这是当前状态的记录，不是计划。
