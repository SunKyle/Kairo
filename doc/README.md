## 五、编号与引用

编号只为跨文档引用稳定，不表示阅读顺序：P（产品）、A（对话/体验）、C（角色/创建）、G（配图）、I（接口/发图/标签）、S（System Prompt）、B（架构）、D（设计/维护）。合并后的新文档沿用该组首号（C01 / A01 / A02 / G01 / S01），旧号随原文归档，不再分配给新文档。

正文引用优先写《文档名》与符号名（如 `chatSystemPrompt`），**不写文件名加行号** —— 行号随代码移动，符号名不会。细节见《贡献与维护规范》§1。
