## 4. 本地 Node vs Vercel Serverless 差异（部署等价性）

| 维度 | 本地（server/index.js） | Vercel（api/index.js） |
| --- | --- | --- |
| 鉴权 | 无 | 无（= 开放代理，S-1） |
| 上游超时 | 120s（自管） | 受函数执行上限约束，需 `maxDuration`（S-3） |
| 请求体上限 | express 15mb 给友好 413 | 平台约 4.5MB 先行拦截（S-4） |
| 限流 | 单进程内存滑窗有效 | 按实例、冷启清零、非全局（已知短板） |
| trust proxy | 仅 `ON_SERVERLESS` 开；本地按 socket 地址 | 取 XFF 第一段（两端口径不可比，需文档化） |
| 私网目标 | 本地开发默认放行回环/内网 | Vercel 一律 400（同一配置两种行为，需文档化） |
| SPA fallback | 仅 `dist/` 存在时托管+兜底（未 build 的克隆直起后端得裸 404） | 平台兜底，函数内 static 分支不可达 |
