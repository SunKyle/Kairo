# 设计系统 · 本项目落地

> 《整体设计风格.md》是**可复用的设计语言**（抽象原则），本文是它在 **Kairo 项目里的具体落地**（真实 token、断点、组件约定）。读设计原则看那份，读「本站到底怎么做的」看这份。
> 快照：main @ 350c54a（2026-10-15）
> 落点：`src/style.css` 的 `:root` 与 `html[data-theme="dark"]` 两块 —— 全站字号/颜色/间距只在那里定义一处。

### 1.3 彩色分工纪律

| 颜色 | 语义 | 禁止 |
|---|---|---|
| 墨色（`--accent`） | 选中 / 聚焦 / 当前项 / 主操作 | 不做第二品牌色 |
| 金色（`--ai-halo`） | 「机器正在跑」（呼吸光晕） | 不与强调色混用 |
| 红色（`--danger`） | 删除 / 报错 / 失败 | 不用于普通强调 |

> `--ai-from` / `--ai-to`（粉紫渐变）已删除：画布页移除后全仓零消费（2026-10-12）。`--ai-halo` 是活的（`.halo-breathe` 消费），不要误删。

## 4. 间距 / 圆角 / 阴影 / 过渡

### 4.1 间距（4px 基准，8px 网格）

`--sp-1` = 4px，`--sp-2` = 8px，`--sp-3` = 12px，`--sp-4` = 16px，`--sp-5` = 24px，`--sp-6` = 32px，`--sp-7` = 48px，`--sp-8` = 64px。

### 4.2 圆角

`--r-sm` = 8px（Tag / 图标键）· `--r` = 16px（卡片 / 输入框）· `--r-lg` = 24px（Prompt Composer / 模态）。

> 圆形键的圆角该比卡片小一档，避免同心弧打架。

### 4.3 阴影

`--sh-sm` = `0 8px 30px rgba(0,0,0,0.06)`（普通组件）· `--sh-md` / `--sh-float` = `0 20px 60px rgba(0,0,0,0.12)`（重要组件 / 悬浮弥散）。深色主题下加深（0.4 / 0.5）。

### 4.4 过渡

`--dur` = 220ms · `--ease` = `cubic-bezier(0.32, 0.72, 0, 1)`（全站唯一缓动曲线）。只动 `opacity` 与 `transform`。

## 5. 响应式断点（语义断点，非设备断点）

| 断点 | 语义 |
|---|---|
| **860px** | 两栏收单栏 |
| **720px** | 触控 / 竖排：浮层堆叠、工具栏横排、底图 `fixed` 退回 `scroll`（窄屏注意 `background-attachment: fixed` 的性能坑） |

> 移动端地址栏收放会让 `100vh` 跳动，用 `dvh` 并保留 `vh` 兜底。

## 6. 组件语言（全站一致）

- **卡片**：无边框 + 圆角 + 接触影；图片全出血；悬停极小位移 + 阴影加深 + 图片轻微放大（宁小勿大）。
- **按钮三档**：主操作（强调色实心药丸，一屏一个）/ 次级（描边药丸）/ 图标键（圆形中性底，压图上时半透明 + 毛玻璃）。触控目标 ≥40px。
- **当前项**：「淡底 + 强调描边 + 强调字」统一语言，不每种组件各发明一套。
- **在途反馈**：呼吸光晕 / 扫描线，用**状态色**（`--ai-halo`），不用强调色。
- **破坏性操作**：底部居中提示条 + 4.5s 倒计时撤销 + 流逝细线；操作结果提示挂**全局层**（固定定位浮条）。
- **遮罩与浮层**：深色 + 毛玻璃（与主题无关）；大图浏览大圆角 + 深投影；浮层有键盘契约（Esc 逐层退、左右翻页、Tab 焦点圈、关闭后焦点归还）。

---

## 7. 无障碍硬约束

- 全站 `:focus-visible` 兜底描边；键盘可达元素不用 `display: none` 隐藏（用透明度，保 Tab 可达）。
- `prefers-reduced-motion` 下取消位移、呼吸停在最亮帧（保留「它在忙」的信息）。
- **对比度硬约束**：最弱一级文字在各自主题面满足小字可读（**约 4.6:1**）。沉浸页背景是图片，取不到计算样式背景色，替代方案是两种主题各拍一张用眼睛过（`measure-history.mjs --shot-dir`）。
