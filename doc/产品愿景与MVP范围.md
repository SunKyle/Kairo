# 产品愿景与 MVP 范围

> 本文是 PRD 的**精炼版**，从《产品路线图.md》§1 提取。原文以 Notion《Kairo 产品需求文档（PRD）》为准，本文只保留「新人 10 分钟能读懂」的骨架。
> 快照：main @ 350c54a（2026-10-15）

---

## 1. 一句话愿景

Kairo 是一款以**角色陪伴为主、情感陪伴为辅**的 AI 陪伴产品。长期目标是多模态、沉浸式的角色陪伴体验：

- 角色有稳定的人格、背景、兴趣、生活习惯、视觉形象与声音；
- 用户可与多个角色分别建立独立关系；
- 角色能记住重要信息，并在恰当时自然回忆；
- 角色的情感表达和相处方式可随长期互动自然发展，但核心人格保持稳定；
- 角色可结合对话分享图片，并在用户允许的范围内主动开启互动；
- 未来逐步扩展语音输入、实时语音对话和更丰富的场景交互。

## 2. MVP 目标

先建立有辨识度的角色陪伴闭环：

> **创建角色 → 开始聊天 → 形成记忆与关系 → 通过图片和语音增强陪伴 → 用户管理偏好与隐私。**

## 3. MVP 范围（A–J）

| 模块 | 一句话要求 |
|---|---|
| **A 角色创建与设定** | 文字/参考图/两者组合创建；AI 自动填充可编辑设定并区分「用户提供 / AI 补全 / 待确认」；先生成主视图，其余设定图以主视图为参考；默认五类设定图 |
| **B 多角色聊天** | 多角色独立聊天；人格/语境/偏好/关系/记忆共同决定表达；角色可表达不同意见 |
| **C 关系发展** | 每角色独立关系状态，等级/进度对用户可见；受有意义互动影响而非消息数；等级不解锁内容、不因缺席扣减 |
| **D 人格与相处偏好** | 核心人格稳定；长期互动长出新的相处模式；用户可调相处偏好（主动/幽默/直接/节奏/安慰），偏好是指导不是重写人格的命令 |
| **E 记忆系统** | 智能筛选而非全量保存；四类记忆；独立记忆中心；展示来源与推断性质；可手动补充 |
| **F 跨角色记忆与隐私** | 角色专属记忆默认私有；跨角色共享需用户明确授权，可查看、可撤销 |
| **G 角色虚拟生活** | 适度表现：稳定兴趣/目标/习惯，适时分享虚拟日常话题；不做复杂后台模拟 |
| **H 聊天中的图片分享** | 对话驱动自然分享；固定形象 + 场景自由变化；不必每条配图；辨识度优先于创意 |
| **I 角色语音** | 按需播放，不强制自动朗读；每角色可配不同声音；播放/暂停/重播；不取代文字 |
| **J 主动联系** | 站内消息 + 可选浏览器通知；全局每天 0–3 次上限；角色优先级；免打扰；通知默认只显示角色名不显示正文；未回复不降关系 |

## 4. 信息架构（PRD §5）

首页（角色展示为主 + 最近聊天为辅）、角色创建页、角色详情页、聊天页、**记忆中心**、其他管理入口（关系与相处偏好、主动联系与通知、全局设置）。

## 5. PRD 明确「不做」（MVP 暂不纳入）

实时语音通话、连续语音对话、复杂 3D/数字人、完整虚拟生活模拟、连续视觉状态系统、大规模主动联系自动化、关系等级解锁内容/任务刷好感/缺席衰减。
