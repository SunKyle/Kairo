# 设计思想与风格指南

> 一份可复用到其他网站的设计语言。抽象出「为什么这么做」与「怎么做」，不绑定具体项目与数值。

---

## 一、核心理念

**克制 · Editorial · 内容优先 —— 让能力隐藏，让过程自然。**

好的界面应该像一副好的画框：它托住内容，但不抢戏。三条不可动摇的基调：

1. **内容优先。** 界面是内容的相框与底板，不是主角。有真实图片/内容的地方就不加装饰边框；能靠留白和层次解决的，不靠线条和色块。
2. **一个强调色就够。** 全站只保留一个「强调」语义（通常就是墨色或最深的中性色），用于选中、当前、焦点、主操作。引入第二个品牌色之前先问：它真的在说一件不同的事吗？
3. **颜色是信息，不是装饰。** 除了强调色，其余一律交给中性灰阶 + 一点点带温度的底色（暖白或暖黑）。颜色只在它承担明确语义时才出现。

> 判断标准：如果把全站截屏去色，信息层级是否依然清楚？如果会，说明层级做在了明暗、字重、间距上，而不是靠颜色硬凑。

---

## 二、色彩策略

### 2.1 中性色打底

- 用**带一点温度的中性色**，避免纯黑纯白：浅色主题走暖白纸感，深色主题走暖黑，而不是 `#FFF` 与 `#000`。这一点暖度是「高级感」最廉价的来源。
- 建立一条完整的**灰度阶梯**：页面底 → 二级面 → 卡片面 → 悬浮面，加上四级文字灰（正文 / 次级 / 三级 / 禁用）。所有层级从这一套里取，不要临时调色。

### 2.2 强调色单一化

- 强调色同时承担「选中态底」「焦点环」「主按钮底」几种角色。保留各自语义命名，但**底层取值同一个** —— 将来要引入品牌色时只需改一处。
- 深色主题下强调色**反相**（墨色 → 纸色），因为墨色在暗底上会消失。

### 2.3 彩色严格分工

如果确实需要彩色，让每种颜色只承担**一种**语义，并明确写下它出现在哪里：

| 用途 | 语义 |
| --- | --- |
| 强调色 | 选中 / 当前 / 焦点 / 主操作 |
| 状态色（如金色/琥珀） | 「机器正在跑 / 正在进行」，与强调完全分开 |
| 危险色 | 删除、报错、失败 |
| 特殊色（如品牌渐变） | 只在某一类入口或身份上出现，不扩散 |

> 关键纪律：**状态色和强调色要是两回事。** 用户一眼要能分辨「这是被选中了」还是「它正在忙」。

## 三、排版

### 3.1 字体

- 正文与标题用**系统字体栈**：各端最合适，还原生、零加载成本。
- 只在品牌字标处用一个有性格的显示字体（几何粗体 + 手写体之类），**自托管且只引需要的子集**。
- 不要写一个从未实际加载的字体名 —— 那等于让兜底色冒名顶替首选，不同机器看到的字形还不一致。

### 3.2 字阶

- 字阶**按角色命名**，不按大小命名（正文 / 次级 / 标签 / 输入 / 标题），全站只在一处定义。
- 刻意保留密集的相邻档位（如 11/12/13/14/15/16）：**合并它们会改变信息层级，那是改设计而不是收敛。**
- 输入框字号不小于 16px，防止 iOS Safari 聚焦时放大整页。

### 3.3 字距

- 大字收负字距（标题、首屏大字），小字大面积用轻微正字距。
- **全大写微标签必须有明显加宽的字距**：这是它「看起来是刻意设计的」而不是「忘了改大小写」的原因。给这一档单独命名。

### 3.4 Editorial 手法

- **眉标（Eyebrow）**：全大写 + 加宽字距 + 中高字重 + 弱化灰，放在标题上方。用一行小字把区块「分类」，是低成本建立 Editorial 感的手段。
- 标题与副标题形成明确落差；副标题限宽（约 50–70 字符），过长一行读起来散。

## 四、布局

### 4.1 统一栏宽

- 全站一级页面**共用同一条最大栏宽与左右留白**（用 `clamp` 让留白随视口伸缩）。跨页切换时左缘对齐，是「同一站」最直接的信号。

### 4.2 顶栏

- 顶栏三段式：左品牌 / 中导航 / 右全局操作。导航居中，滑块位置即当前页。
- 顶栏常驻（`sticky`），滚动后出现一条**通栏毛玻璃底衬 + 发丝分隔线**：既让内容从下面穿过，又保证导航始终可读。

### 4.3 网格

- 内容用**自适应网格**（`auto-fill` + 最小宽度）或**定宽多列瀑布流**（`column-width`），让列数随容器变化，而不是给每个断点写一套列数。
- 卡片网格的最小宽度决定「几列」，间距用统一栅格。

### 4.4 层次与留白

- 用**明暗面**（底 / 二级面 / 卡片面 / 悬浮面）表达层次，而不是靠边框。
- 分组分隔线**两端留空**、不横贯整块：留白本身就是分组，线只是提示。

## 五、组件语言

### 5.1 卡片

- **无边框、圆角、接触影**：靠一圈贴边接触影 + 一道弥散影托住卡片，边缘干净利落。
- 有图片的卡片让图片**全出血铺满**，不做内边距缩进。
- 悬停做**极小的位移 + 阴影加深 + 图片轻微放大**。位移宁小勿大（几个像素），大了就像在跳。

### 5.2 按钮分级

只保留清晰的两三档，让主次一眼分明：

| 级别 | 做法 |
| --- | --- |
| 主操作 | 强调色实心药丸，一屏一个，悬停压深、按下微缩 |
| 次级 | 描边药丸，悬停加深描边 + 淡底 |
| 图标键 | 圆形，中性底，压在图片上时用半透明 + 毛玻璃 |

- 触控目标不小于 40px；窄屏把偏小的键统一升到 40px。
- 圆形键的圆角该比卡片小一档，避免同心弧打架。

### 5.3 状态与反馈

- **当前项**用「淡底 + 强调描边 + 强调字」的统一语言，不要每种组件各发明一套。
- **长时操作要有在途反馈**：光晕呼吸、扫描线、加载动效，让用户知道「它在跑」而不是卡死。在途状态用**状态色**（见 2.3），别用强调色。
- **破坏性操作提供后悔药**：底部居中提示条 + 倒计时撤销，并把「正在流逝」用一条细线可视化。
- 操作结果提示**挂到全局层**（固定定位的浮条），确保在任何页面可见，不被局部容器裁切。

### 5.4 遮罩与浮层

- 遮罩统一用**深色 + 毛玻璃**，与主题无关（照片浏览场景下，遮罩不该跟着浅色主题变亮）。
- 大图浏览：图片大圆角 + 深投影、翻页键压在图上、一个位置指示（第几张/共几张）。
- 浮层要有**键盘契约**：Esc 逐层退、左右翻页、Tab 焦点圈在浮层内、关闭后焦点归还触发处。

### 5.5 毛玻璃的正确用法

- **一个元素承载**背景虚化与压暗，避免两条边不重合。
- **mask 羽化到透明**，让虚化边缘比压暗边缘伸得更远 —— 这样不会露出一块矩形硬边。
- 虚化只加 `blur`，**不要加亮度/饱和度**滤镜：在羽化处会产生色调平移，肉眼会看到边界。
- 文字压在半透明面上时，用双层文字投影兜可读性。

## 六、动效

- **缓动统一**：一套主缓动贯穿全站，控件类可用带轻微回弹的弹簧曲线。不要每个组件各配一条。
- **时长分层**：入场略慢、离场快、悬停反馈最快；小幅位移动画可以慢一点，读起来是「稳」而不是「卡」。
- **动效要说明状态，不是装饰**：呼吸=在忙、位移=层级变化、缩放=被聚焦。
- 呼吸类动效周期偏慢（约 2 秒），传达的是「稳着在做一件事」而非催进度。
- 只动画 `opacity` 与 `transform`，把重排代价交给合成层。

---

## 七、响应式

- 断点按**语义**分，不按设备分：约 **860px**（两栏收单栏）、**720px**（触控 / 竖排：浮层堆叠、工具栏横排、底图 `fixed` 退回 `scroll`）、**640px**（顶栏换两行、网格列距收窄）。
- 移动端注意 `background-attachment: fixed` 的性能坑，窄屏退回普通滚动。
- 移动端地址栏收放会让 `100vh` 跳动，用 `dvh` 并保留 `vh` 兜底。

---

## 八、无障碍与一致性

- 全站给一个 `:focus-visible` 兜底描边；同理，键盘可达的元素**不要用 `display: none` 隐藏**，用透明度隐藏，保证仍能 Tab 聚焦并显形。
- 动效尊重 `prefers-reduced-motion`：取消位移、呼吸停在最亮帧（保留「它在忙」的信息）、加载动效给出完整结果态。
- 文字对比度：最弱的一级文字在各自主题面上也要满足小字可读（约 4.6:1）。
- **一致性优先于局部最优**：同一语义（当前项、危险、在途）在全站用同一套视觉，宁可某处不够惊艳，也不要用户重新学习。

## 九、一页速查

| 维度 | 原则 |
| --- | --- |
| 理念 | 克制 · 内容优先 · 一个强调色 |
| 颜色 | 暖中性打底；强调色反相适配深色；彩色只承担单一语义 |
| 排版 | 系统字体；字阶按角色；全大写微标签加宽字距；输入框 ≥16px |
| 布局 | 统一栏宽；毛玻璃顶栏；自适应网格；明暗面分层，不靠边框 |
| 卡片 | 无边框 + 圆角 + 接触影；全出血；悬停小幅位移微缩放 |
| 按钮 | 主/次/图标三档；一屏一个实心；触控 ≥40px |
| 反馈 | 在途有呼吸；破坏性有撤销；提示挂全局层 |
| 动效 | 一套缓动 + 时长分层；只动 opacity/transform；尊重减少动效 |
| 响应式 | 860 / 720 / 640 三个语义断点 |
| 无障碍 | 焦点兜底、透明隐藏保可达、对比度达标、可减动效 |
