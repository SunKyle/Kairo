## 2. 自查方法


### 2.1 版本号自查

```bash
# DB 版本
grep -n "DB_VERSION" src/lib/idb.ts

# 测试规模（运行后看输出）
npm test

# 页面数量
grep -n "Page =" src/lib/nav.ts
```

### 2.2 引用自查

```bash
# 找出所有「文件 + 行号」引用
grep -rn "#L[0-9]" doc/

# 找出所有指向不存在文件的引用（粗查）
grep -rhn "](\.\./" doc/ | head -20
```

### 2.3 死链自查

```bash
# 列出 doc/ 下所有文档的相对引用，逐个验证是否存在
grep -rhoE "\]\(([^)#]+\.md)" doc/ | sort -u
```

## 3. 更新纪律

1. **代码有重大变动后**，按本文 §1 的清单逐条核对受影响文档。
2. **新增文档时**，检查是否与本文清单冲突（例如又写了「文件+行号」引用）。
3. **每完成一个 T 任务**，在《产品路线图.md》§7 追加记录，并检查相关文档是否需要「此后已漂移」补记。
4. **发现新的不一致**，追加到本文 §1，不要直接改快照正文。
