## 1. 一句话结论

把"说 / 想 / 做"建成**三条独立的消息**，每条带一个 `layer` 字段（`say | think | act`），而不是把"想 / 做"用行内标签塞进正文里剪。

三者不是三种排版，是三种**信息归属规则**——排版只是它们的表面。真正要设计的是"谁能看见、会不会进入角色之后的记忆"，规则定死，视觉自然落下来。

## 2. 三层的定义与不对称

- **说（say）**：对话。双方可见、算"说出口的事实/承诺"、进长期记忆。每轮必有。
- **想（think）**：角色的内心独白。只对用户揭示，是**亲密感的来源——来自不对称**：用户能窥见 ta 没说出口的话，但 ta 听不见用户的内心。
- **做（act）**：动作 / 旁白。第三人称的舞台提示（\*她把围巾绕紧\*）。是**共享世界里真发生的事**，双方都"经历"。

三条刻意不对称：
1. **用户没有 `think`**——用户能"说"，但"想"只对角色开放。一旦允许用户发 `think`，就等于默许角色读心，拟人感立刻崩。这是保护拟人的护栏，不是功能缺失。
2. **角色能记起自己的 `think`，但不该把它当"你已知的事实"引用**——隔几轮 ta 回头补一句"刚才我本想…"是加分（人本来会想起自己的念头）；把内心当成公开承诺才是破功。
3. `think` 的内容**不算对用户的承诺/事实**，它私密、可反悔，不能固化成长期"事实"。

## 3. 为什么用消息级 `layer`，而不是再走一套行内标签

现有的 `[photo:]` / `[mood:]` 是**值标签**：从一段正文里剪一枚意图，**附在这同一条消息上**。photo/mood 天然是"对一句话的注解"，留在标签层里对，也继续走 [标签层通用化设计.md](./标签层通用化设计.md) 那条重构通道。

think / act 不一样：**它们本身就是完整的一句独立表达**。硬塞进正文用 `chatTags` 按位置剪，会把那个"切三路"的债再叠两枚 kind，而且让"开关展示 / 按层过滤记忆"变成一堆脆弱正则。做成消息级后：

- 展示开关 = **按 `layer` 过滤**，一行 filter，纯函数可测；
- 进不进记忆 = **压缩时按 `layer` 丢弃**，判据集中；
- 连发、reaction 本就是消息级，一以贯之。

**这条选择把 think/act 划在 `chatTags` 之外**，所以它**不加重标签层的通用化债务**——那份 memo 的触发点是"再加第 3、4 种行内值标签（music/video）"，think/act 不走那条，不构成新触发。

**产出机制（怎么从一轮里分出多层）**：模型在一轮回复里用**成对区域标记**划段（建议 `[think]…[/think]`、`[act]…[/act]`，具体记号待定，见 §9），服务端按标记把这一轮**扇出成多条有序消息**，落到标记外的默认是 `say`。区域标记比值标签稳得多——不需要 `[` 位置白名单，一个 `currentLayer` 游标 + open/close 即可，天然免疫 `chatTags` 那套"位置切三路"的坑。

**与其它形态正交**：`layer` 描述的是**话语的心理语域**；photo 是一条 `say` 消息携带的图片、mood 是 `say` 的属性、music/video 走值标签通道——都和 `layer` 不冲突。

## 4. 数据模型（additive，不升 DB_VERSION）

```ts
// types.ts
type MessageLayer = 'say' | 'think' | 'act'
interface ChatMessage {
  // …existing
  layer?: MessageLayer   // 缺省=按 'say' 处理；载入时 coerce 空/未知值为 'say'
}
```

- 照 `origin` / `pinned` 的加法纪律：可选字段、不升 `DB_VERSION`、载入时把缺失 coerce 成 `'say'`，旧数据零迁移。
- think / act 各自是一条 `ChatMessage` 行，`text` 就是那句内心 / 那条动作；`role` 恒为助手（用户没有 think，act 本轮也归角色侧，用户能不能打 act 见 §9）。

## 5. 逐层规则矩阵（本 memo 的核心，把参数拍死）

| 层 | 产出条件 | 界面展示（默认） | 模型下一轮输入（短期上下文） | 进长期记忆（chat_summaries） |
|---|---|---|---|---|
| **say** | 每轮必有 | 恒展示 | 保留 | 保留（算事实 / 承诺） |
| **think** | 情绪浓、或"说的 ≠ 想的"时才有，**非每条** | **默认展示**，可全局关 | **保留**（ta 记得自己刚想过什么） | **不进** |
| **act** | **仅"场景模式"开启时产出** | 场景内默认展示，可关 | 保留（本轮动作是真实经历） | 只进**实质动作**；氛围动作压缩时丢弃 |

三处留白的取舍理由：

- **think「不进长期摘要」但「留短期上下文」**：不进摘要，是为了别把主观内心固化成事实（免得"我其实嫌你烦"被永久摘要、日后被当承诺引用）；留短期，是因为角色记得自己上一轮想过什么很自然，连续性靠它。代价：越过滑动窗口后 ta 会"淡忘"具体内心，情绪残响交给现有 mood 层（见 [角色情感系统设计.md](./角色情感系统设计.md)）承接，够用。
- **act「短期全留、长期只留实质」**：动作是共享事件，ta 不能对自己的行动失忆；但纯氛围（\*低头\*\*绕围巾\*）进摘要只会污染记忆。**区分"实质 / 氛围"只在蒸馏那一步用一个轻启发做，不要求模型每轮分类**，成本可控。
- **"关了展示会不会泄露"不算 bug**：act 事件真发生过，用户只是关掉美化文字；ta 引用那次动作是对的，用户也清楚自己关了旁白。展示开关只管**界面呈现**，不回写记忆 / 模型输入。

## 6. 场景模式：`act` 的定位，也是那盏"信号灯"

规则记成一句：**日常模式 = say + think；场景模式 = say + think + act**。`act` 就是定义"是否进了场景"的那个 delta。

- **场景模式是一个显式状态 / 开关，由它 gate `act` 产不产出**——不要靠"模型这轮有没有打旁白"去反推点亮，否则 `act` 忽有忽无、信号灯会闪。灯跟着状态走，不跟着标签频率走。
- 顺带解决了"现实里没人发微信还打星号配旁白"的出戏感：出戏只发生在日常模式，而日常模式本就不产出 `act`。
- 进入 / 退出机制（用户切？角色自己声明？随剧本？）见 §9。

## 7. 触发与稀缺（油腻与否的命门）

- **think**：只在"内心 ≠ 口头"或情绪强烈时漏一句，非每条都写。触发阈值可直接接现有 mood 强度——强情绪才允许内心泄露。
- **act**：场景内也是点缀节拍（开场定位、关键动作、转场），不是每句都旁白。
- 二者共用一条纪律：**能少则少**。满屏 think/act 会瞬间掉进三流同人文质感，稀缺才是亲密感。

## 8. 视觉编码（用"人称 + 对齐 + 包裹"三重硬信号，别只靠斜体）

think 与 act 若都是"斜体 + 弱化色"，同屏必糊。拉开靠人称：

- **say** = 气泡（右 = 用户实心墨 `--accent`，左 = 角色白卡 + 细描边）。
- **think** = **第一人称**、无气泡、左缩进 + 一条细竖线、斜体弱化（"我停在那儿看了好久"）。
- **act** = **第三人称**、居中、星号 / 全角括号包裹、更弱（\*她把围巾又绕紧了一圈\*）；场景模式下整条 thread 可压一层极淡场景底。

人称差（"我…" vs "\*她…\*"）是模型一眼能判、用户一眼能分的硬信号，比颜色可靠。配色 / 暗色遵循现有 token：文字走 `--muted` / `--faint`，暗色下 `html[data-theme=dark]` 要提亮 fg 否则读不出；**别写死 `#fff`**（双主题反相坑）。

## 10. 风险

| 风险 | 缓解 |
|---|---|
| think 留短期 → 模型可能频繁"引用自己没说出口的内心"，显啰嗦 | prompt 明确"内心是私密泄露、不轻易复述"；短期只保留最近若干轮 think，超窗自然淡忘 |
| act 的"实质 / 氛围"启发式误判，重要动作被压缩丢掉 | 判据做成可测纯函数 + 保守默认（拿不准算实质、保留）；先灰度看摘要质量 |
| 区域标记模型不遵守（忘闭合 / 错位） | 未闭合 = 到轮尾按 `currentLayer` 收尾（复用 tailHold 思路）；错位的当正文，宁多不可漏 |
| 三层同屏视觉糊 | §8 三重硬信号；出对比样张（已交 `kairo-message-forms.html`）验收，不靠颜色单打独斗 |
| 展示开关与记忆解耦，用户以为"关了=删了" | 文案点明"仅隐藏、事件仍在"；或提供"连隐藏内容一起不喂模型"的高级项（可选） |

## 11. 决策记录与剩余参数

**已定（2026-10-17）：**

1. ✅ **脊柱 A** —— think / act 走**消息级 `layer`**、扇出成多条，**不**用行内值标签。§3 / §9 随之锁死，且**不触发标签层重构**。
2. ✅ **脊柱 B** —— `think` = **留短期上下文、只挡长期摘要**（`keepInModelHistory` 对 think 返 `true`、`keepInSummary` 返 `false`）。内心线越窗淡忘后由现有 mood 承接残响，够用。

**推荐默认（点头即锁）：**

3. **场景进入 / 退出 = 角色驱动的迟滞开关 + 用户手动 override**。首个 `act` 触发进入并**保持**（不因后续没旁白就灭，避免信号灯闪）；只在场景边界（时间分隔线 / 话题切回日常 / 用户显式退出）触发离开。用户侧留一个强制开 / 关的 override 钉住——既让角色主导氛围，又不会让灯乱眨。
4. **默认值与用户侧**：
   - `think` 展示**默认开**——它是超拟人的招牌亲密特征，默认藏起来等于白做；嫌出戏的用户一键关。
   - **用户可打 `act`，与角色 `act` 同受场景模式这道闸**（场景里双方都能演、日常里都不演）——对称、复用同一 gate，边际成本低。
   - **用户仍不能 `think`**——读心护栏不变（§2）。
