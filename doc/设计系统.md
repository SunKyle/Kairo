# 设计系统

> 本文合并了原《整体设计风格.md》（可复用的设计语言）与《设计系统-本项目落地.md》（Kairo 的真实 token 与组件约定）。前半说「为什么」，后半说「本站到底取什么值」。
> 快照：`main` @ `6abb48e`（2026-10-20）。唯一落点：`src/style.css` 的 `:root` 与 `html[data-theme="dark"]` —— 全站字号、颜色、间距只在那里定义一处。

---

## 一、核心理念

**克制 · Editorial · 内容优先 —— 让能力隐藏，让过程自然。**

好的界面像一副好的画框：它托住内容，但不抢戏。三条不可动摇的基调：

1. **内容优先。** 界面是内容的相框与底板，不是主角。有真实图片/内容的地方不加装饰边框；能靠留白和层次解决的，不靠线条和色块。
2. **一个强调色就够。** 全站只保留一个「强调」语义（墨色），用于选中、当前、焦点、主操作。引入第二个品牌色之前先问：它真的在说一件不同的事吗？
3. **颜色是信息，不是装饰。** 除强调色外一律中性灰阶 + 一点带温度的底色。颜色只在承担明确语义时出现。
4. **一致性优先于局部最优。** 宁可某处不够惊艳，也不要用户重新学习。

> 判断标准：把全站截屏去色，信息层级是否依然清楚？如果会，说明层级做在了明暗、字重、间距上，而不是靠颜色硬凑。

## 二、色彩

### 2.1 策略

用**带一点温度的中性色**打底，避免纯黑纯白：浅色主题走暖白纸感，深色主题走暖黑。建立完整灰度阶梯（页面底 → 二级面 → 卡片面 → 悬浮面，再加四级文字灰），所有层级从这一套里取，不临时调色。

深色主题下强调色**反相**（墨色 → 纸色），因为墨色在暗底上会消失。状态色与危险色各自独立，**绝不与强调色混用** —— 用户一眼要能分辨「这是被选中了」还是「它正在忙 / 出错了」。

### 2.4 彩色分工纪律

| 颜色 | 语义 | 禁止 |
|---|---|---|
| 墨色（`--accent`） | 选中 / 聚焦 / 当前项 / 主操作 | 不做第二品牌色 |
| 金色（`--ai-halo`） | 「机器正在跑」（呼吸光晕） | 不与强调色混用 |
| 红色（`--danger`） | 删除 / 报错 / 失败 | 不用于普通强调 |

> `--ai-from` / `--ai-to`（粉紫渐变）已删除：画布页移除后全仓零消费（2026-10-12）。`--ai-halo` 仍是活的（`.halo-breathe` 消费），不要误删。

## 三、字体与排版

### 3.1 字体

| token | 值 | 用途 |
|---|---|---|
| `--font-sans` | `-apple-system, BlinkMacSystemFont, "Segoe UI", system-ui, "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif` | 全站正文与标题（系统无衬线，零加载成本） |
| `--font-serif` | `Georgia, "Times New Roman", "Songti SC", "Noto Serif SC", "Source Han Serif SC", serif` | **只给沉浸页台词用**（`ChatPage` 的 `.is-immersive`），全站唯一例外 |
| `--font-wordmark` | `"Poppins", "Avenir Next", "Futura", "Century Gothic", sans-serif` | 字标几何粗体（自托管，只引 latin） |
| `--font-script` | `"Pacifico", "Snell Roundhand", "Brush Script MT", cursive` | 字标手写体（自托管，只引 latin） |

> 刻意不写 "Inter"：之前写了却从未加载，等于让兜底链冒名顶替首选，不同机器看到的字形还不一致。

### 3.2 字阶（按角色命名，全站只此一处）

| token | 值 | 角色 |
|---|---|---|
| `--fs-micro` | 11px | 图片浮层、极小注解 |
| `--fs-xs` | 12px | 小标签、胶囊、提示 |
| `--fs-sm` | 13px | 次级正文、按钮、表单控件 |
| `--fs-base` | 14px | 正文 |
| `--fs-md` | 15px | 预览卡提示词（刻意比正文大一档） |
| `--fs-lg` | 16px | 输入框（防 iOS Safari 聚焦放大） |
| `--fs-xl` | 20px | 区块标题、窄屏页标题 |
| `--fs-2xl` | 22px | 面板标题 |
| `--fs-3xl` | 28px | 页标题 |

> 字阶**按角色命名，不按大小命名**。刻意保留密集的相邻档位（11/12/13/14/15/16）：合并它们会改变信息层级，那是改设计而不是收敛。字标的 21px / 24px 不在此列（品牌锁形的一部分）。

### 3.3 字距

| token | 值 | 用途 |
|---|---|---|
| `--ls-tight` | -0.02em | 标题 |
| `--ls-wide` | 0.01em | 副标题轻微松开 |
| `--ls-eyebrow` | 0.14em | **全大写微标签专用**（必须比 `--ls-wide` 大一档） |

> 低于 0.01em 的差异在 15px 上不足 0.15px，肉眼无法分辨，所以不设中间碎档。

### 3.4 Editorial 手法

**眉标（Eyebrow）**：全大写 + 加宽字距 + 中高字重 + 弱化灰，放在标题上方。用一行小字把区块「分类」，是低成本建立 Editorial 感的手段。标题与副标题形成明确落差；副标题限宽（约 50–70 字符），过长一行读起来散。

## 四、间距 / 圆角 / 阴影 / 过渡

**间距**（4px 基准，8px 网格）：`--sp-1` 4 · `--sp-2` 8 · `--sp-3` 12 · `--sp-4` 16 · `--sp-5` 24 · `--sp-6` 32 · `--sp-7` 48 · `--sp-8` 64（均 px）。

**圆角**：`--r-sm` 8px（Tag / 图标键）· `--r` 16px（卡片 / 输入框）· `--r-lg` 24px（Prompt Composer / 模态）。圆形键的圆角该比卡片小一档，避免同心弧打架。

**阴影**：`--sh-sm` = `0 8px 30px rgba(0,0,0,0.06)`（普通组件）· `--sh-md` / `--sh-float` = `0 20px 60px rgba(0,0,0,0.12)`（重要组件 / 悬浮弥散）。深色主题下加深（0.4 / 0.5）。

**过渡**：`--dur` = 220ms · `--ease` = `cubic-bezier(0.32, 0.72, 0, 1)`（全站唯一缓动曲线）。只动 `opacity` 与 `transform`。

## 五、布局与响应式

**统一栏宽。** 全站一级页面共用同一条最大栏宽与左右留白（用 `clamp` 让留白随视口伸缩）。跨页切换时左缘对齐，是「同一站」最直接的信号。

**顶栏。** 三段式：左品牌 / 中导航 / 右全局操作；导航居中，滑块位置即当前页。顶栏常驻（`sticky`），滚动后出现通栏毛玻璃底衬 + 发丝分隔线，让内容从下面穿过又不失可读。

**网格。** 内容用自适应网格（`auto-fill` + 最小宽度）或定宽多列瀑布流（`column-width`），让列数随容器变化，而不是给每个断点写一套列数。

**层次与留白。** 用明暗面（底 / 二级面 / 卡片面 / 悬浮面）表达层次，而不是靠边框。分组分隔线两端留空、不横贯整块：留白本身就是分组，线只是提示。

**断点（按语义分，不按设备分）：**

| 断点 | 语义 |
|---|---|
| **860px** | 两栏收单栏 |
| **720px** | 触控 / 竖排：浮层堆叠、工具栏横排、底图 `fixed` 退回 `scroll` |
| **640px** | 顶栏换两行、网格列距收窄 |

> 移动端注意 `background-attachment: fixed` 的性能坑；地址栏收放会让 `100vh` 跳动，用 `dvh` 并保留 `vh` 兜底。

## 六、组件语言

**卡片。** 无边框 + 圆角 + 接触影：一圈贴边接触影 + 一道弥散影托住，边缘干净。有图片的卡片让图片全出血铺满，不做内边距缩进。悬停做极小的位移 + 阴影加深 + 图片轻微放大（宁小勿大，大了像在跳）。

**按钮三档。** 主操作：强调色实心药丸，一屏一个，悬停压深、按下微缩；次级：描边药丸，悬停加深描边 + 淡底；图标键：圆形中性底，压图上时半透明 + 毛玻璃。触控目标 ≥40px。

**当前项。** 统一用「淡底 + 强调描边 + 强调字」，不要每种组件各发明一套。

**在途反馈。** 长时操作要有在途反馈（呼吸光晕 / 扫描线 / 加载动效），让用户知道「它在跑」而不是卡死；在途状态用**状态色**（`--ai-halo`），不用强调色。呼吸周期偏慢（约 2 秒），传达「稳着在做一件事」而非催进度。

**破坏性操作。** 底部居中提示条 + 4.5s 倒计时撤销 + 流逝细线；操作结果提示挂**全局层**（固定定位浮条），确保任何页面可见、不被局部容器裁切。

**遮罩与浮层。** 遮罩统一深色 + 毛玻璃，与主题无关（照片浏览场景下不该跟着浅色主题变亮）。大图浏览：图片大圆角 + 深投影、翻页键压在图上、一个位置指示。浮层要有键盘契约：Esc 逐层退、左右翻页、Tab 焦点圈在浮层内、关闭后焦点归还触发处。

**毛玻璃。** 一个元素同时承载背景虚化与压暗，避免两条边不重合；mask 羽化到透明，让虚化边缘比压暗边缘伸得更远；虚化只加 `blur`，不加亮度/饱和度滤镜（羽化处会色调平移）；文字压在半透明面上时用双层文字投影兜可读性。

## 七、动效

**缓动统一**：一套主缓动贯穿全站，控件类可用带轻微回弹的弹簧曲线，不要每个组件各配一条。**时长分层**：入场略慢、离场快、悬停反馈最快；小幅位移动画可以慢一点，读起来是「稳」而不是「卡」。

**动效要说明状态，不是装饰**：呼吸 = 在忙、位移 = 层级变化、缩放 = 被聚焦。只动画 `opacity` 与 `transform`，把重排代价交给合成层。

页面转场目前由 GSAP 承担（`App.vue` 的 `<Transition :css="false">` 与 `@enter`/`@leave`）：文档式页面让页头先落、其余 stagger；满屏工作台页（对话页）用 `data-page-motion="fade"` 只淡入，不做位移。

## 八、无障碍

- 全站给 `:focus-visible` 兜底描边；键盘可达的元素用透明度隐藏，**不用 `display: none`**。
- 动效尊重 `prefers-reduced-motion`：取消位移、呼吸停在最亮帧（保留「它在忙」的信息）、加载动效给出完整结果态。
- 文字对比度：最弱一级文字在各自主题面上也要满足小字可读（约 4.6:1）。沉浸页背景是图片、取不到计算样式背景色，替代方案是两种主题各拍一张用眼睛过（`measure-history.mjs --shot-dir`）。
- 输入框字号 ≥16px；触控目标 ≥40px。

## 九、一页速查

| 维度 | 原则 |
| --- | --- |
| 理念 | 克制 · 内容优先 · 一个强调色 · 一致性优先 |
| 颜色 | 暖中性打底；强调色反相适配深色；彩色只承担单一语义 |
| 排版 | 系统字体；字阶按角色；全大写微标签加宽字距；输入框 ≥16px |
| 布局 | 统一栏宽；毛玻璃顶栏；自适应网格；明暗面分层，不靠边框 |
| 卡片 | 无边框 + 圆角 + 接触影；全出血；悬停小幅位移微缩放 |
| 按钮 | 主 / 次 / 图标三档；一屏一个实心；触控 ≥40px |
| 反馈 | 在途有呼吸；破坏性有撤销；提示挂全局层 |
| 动效 | 一套缓动 + 时长分层；只动 opacity/transform；尊重减少动效 |
| 响应式 | 860 / 720 / 640 三个语义断点 |
| 无障碍 | 焦点兜底、透明隐藏保可达、对比度达标、可减动效 |
